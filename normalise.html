Normalise.css

This page is to test the normalise.css file.

Normalise.css is a small CSS file that provides cross-browser consistency in the default styling of HTML elements. It helps to ensure that web pages look and behave consistently across different browsers and devices.

By using normalise.css, developers can avoid common issues related to browser inconsistencies, such as differences in default font sizes, margins, paddings, and other styling properties. It provides a solid foundation for building web pages and allows developers to focus on their own custom styles without worrying about browser quirks.
